# Cloning-xyz

A workspace that collects useful AI/dev tools and keeps a persistent memory of
instructions, rules, learnings, and mistakes.

## Structure

- `.claude/memory/` — persistent memory (instructions, rules, learnings, mistakes)
- `tools/` — collected tools and their install status
- `CLAUDE.md` — guidance for Claude Code (memory workflow + branch rules)

## Memory system

Jab bhi koi instruction, rule, learning, ya mistake ho — wo `.claude/memory/`
me store hoti hai aur GitHub par push hoti hai, taake context kabhi lost na ho
aur same ghalti dobara na duhrayi jaye.
